# POPOQ GAMES — сайт студии

Статичный сайт-визитка: чистый HTML/CSS/JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, заливается на любой хостинг как есть.

---

## Как запустить локально

```bash
cd /home/garnik/popoq_games_web
python3 -m http.server 8000
```

Открыть <http://localhost:8000>.

> Просто открыть `index.html` двойным кликом тоже можно, но локальный сервер
> ближе к реальным условиям (правильно работают пути и кеш).

## Где что лежит

```

js/i18n.js            переключение EN/RU
js/app.js             прелоадер, скролл-эффекты, флип-карты, меню, форма
assets/brand/         логотипы и иконки
assets/games/         ★ сюда клади скриншоты игр
assets/team/          ★ сюда клади фото команды
assets/placeholders/  временные заглушки (заменятся твоими файлами)
popoq-logo/           исходники логотипа (не трогаем)
```

## Как поменять контент

Всё живёт в **[js/content.js](js/content.js)**. Больше никуда лезть не нужно.

### Название игры и описание

```js
{
  id: 'project-one',
  code: '01',
  title: 'PROJECT ONE',          // ← название игры
  status:      { en: 'IN DEVELOPMENT', ru: 'В РАЗРАБОТКЕ' },
  tagline:     { en: '…', ru: '…' },
  description: { en: '…', ru: '…' },
  specs: [ … ]                    // жанр, игроки, дата, платформа
}
```

### Имена команды

```js
{
  name: 'YOUR NAME',              // ← имя
  role: { en: 'Developer & Game Creator', ru: 'Разработчик и создатель игры' },
  bio:  { en: '…', ru: '…' }
}
```

### Реальные картинки

1. Положи файлы в `assets/games/` и `assets/team/`.
2. Поменяй пути в `js/content.js`:

```js
// было
cover: 'assets/placeholders/game-hero-16x9.svg',
shots: ['assets/placeholders/game-shot-1.svg', …],

// стало
cover: 'assets/games/key-art.jpg',
shots: ['assets/games/shot-1.jpg', 'assets/games/shot-2.jpg', …],
```

```js
// команда: front — пиксельный аватар (лицо карточки),
//          photo — реальное фото (оборот, показывается при наведении)
front: 'assets/placeholders/team-front-1.svg',
photo: 'assets/team/garnik.jpg',
```

**Рекомендуемые размеры**

| Что | Пропорции | Размер |
|---|---|---|
| Ключевой арт игры (`cover`) | 16:9 | 1920 × 1080 |
| Скриншоты (`shots`) | 16:9 | 1280 × 720 |
| Фото команды (`photo`) | 4:5 | 800 × 1000 |

### Ссылки на соцсети

```js
links: {
  steam:     'https://store.steampowered.com/app/…',
  discord:   'https://discord.gg/…',
  instagram: 'https://instagram.com/…',
  tiktok:    'https://tiktok.com/@…'
}
```

Пока стоит `'#'` — кнопка отображается неактивной, а не ведёт в никуда.

### Почта

```js
emailName: 'techtrekkershop',
emailHost: 'gmail.com',
```

Адрес специально разбит на две части и **нигде не выводится на страницу** —
ни текстом, ни в разметке. Так его не соберут спам-боты, которые сканируют
сайты в поисках готовой строки с «@».

Форма контактов открывает почтовый клиент посетителя (`mailto:`) — бэкенд не нужен.

> ⚠️ **Важно понимать:** адрес всё равно виден в поле «Кому», когда у человека
> открывается его почтовая программа, и его можно вытащить из `js/content.js`.
> Полностью скрыть адрес можно только через сервис-посредник для форм
> (Formspree, Web3Forms и подобные) — тогда письмо уходит через них,
> а адрес вообще не попадает в код сайта. Скажи, если нужно так.

### Вопросы в FAQ

```js
faq: [
  { q: { en: '…', ru: '…' },     // вопрос
    a: { en: '…', ru: '…' } },   // ответ
  …
]
```

Нумерация (01, 02, …) и аккордеон работают сами — просто добавляй объекты
в массив или убирай ненужные.

### Добавить вторую игру

Скопируй объект внутри массива `games` и поменяй поля. Сетка подстроится сама.
`featured: true` — большая карточка с липким ключевым артом,
`featured: false` — компактный тизер.

## Что уже сделано

- **Адаптив** — телефон / планшет / десктоп, брейкпоинты 480 / 620 / 768 / 1024.
- **FAQ** — аккордеон на 6 вопросов, открыт всегда только один ответ.
- **EN + RU** — переключатель в шапке, выбор запоминается, язык определяется
  автоматически при первом заходе.
- **Флип-карты команды** — наведение мышкой на десктопе, тап на телефоне,
  `Tab` + `Enter` с клавиатуры. Лицо — пиксельный аватар, оборот — реальное фото.
- **Скролл-эффекты** — прогресс-бар, появление блоков, разрезанные на слова
  заголовки, параллакс, липкий ключевой арт, бегущая лента, магнитные кнопки,
  кастомный курсор.
- **Прелоадер** — показывается один раз за сессию.
- **Доступность** — всё движение отключается при `prefers-reduced-motion`,
  везде есть фокус-стили, у картинок `alt`.

## Как выложить в интернет

**Netlify / Vercel** — перетащить папку в веб-интерфейс, готово.

**GitHub Pages:**

```bash
git init && git add . && git commit -m "POPOQ GAMES site"
git branch -M main
git remote add origin https://github.com/<ты>/<репозиторий>.git
git push -u origin main
```

Затем Settings → Pages → Source: `main` / `root`.

**Свой хостинг** — залить содержимое папки в корень домена по FTP.
