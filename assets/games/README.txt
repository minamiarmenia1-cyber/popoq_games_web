СКРИНШОТЫ ИГР
=============
Клади сюда картинки игры, потом пропиши пути в js/content.js.

Рекомендуемые размеры:
  ключевой арт (cover)  16:9   1920 x 1080
  скриншоты   (shots)   16:9   1280 x 720

Формат: JPG для фото/скриншотов, PNG если нужна прозрачность.
Держи файлы легче ~500 КБ — сайт будет быстрее.

Пример имён:
  key-art.jpg
  shot-1.jpg  shot-2.jpg  shot-3.jpg  shot-4.jpg

Затем в js/content.js:
  cover: 'assets/games/key-art.jpg',
  shots: ['assets/games/shot-1.jpg', 'assets/games/shot-2.jpg', ...],
